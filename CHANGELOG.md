## [Unreleased]

### Added

## [1.0.0] - 2026-10-28

### Added

- Full-screen in-page responsive preview with mobile, tablet, desktop, and custom dimensions.
- Twelve built-in presets and user-saved presets.
- Device rotation, responsive ruler, breakpoint markers, and live resize grip.
- URL controls, reload, navigation status, and iframe loading diagnostics.
- Touch simulation for same-origin preview pages.
- Screen-only and device-frame PNG screenshots.
- Tailwind and Bootstrap breakpoint sets, vision filters, and design-image overlay tools.
- Persistent preview state and keyboard shortcuts.
- Declarative Net Request rule for pages that block iframe embedding.
- Manifest V3 toolbar action and automatic content-script recovery on reload.

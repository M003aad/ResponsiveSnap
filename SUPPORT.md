# Support

## Documentation

Start with [README.md](README.md) for installation, features, permissions, usage, shortcuts, and troubleshooting.

## Existing issues

Search [open issues](https://github.com/M003aad/ResponsiveSnap/issues) before creating a report. A similar report may already contain a workaround or status update.

## Questions and bug reports

- Use [GitHub Issues](https://github.com/M003aad/ResponsiveSnap/issues) for reproducible bugs and feature discussions.
- Use the bug report and feature request templates in [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) to include useful details.
- Do not report security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) instead.

## Communication

GitHub Issues are the project-maintained channel for support and coordination. Include the browser, extension version, target page type, and exact reproduction steps so maintainers can respond efficiently.
